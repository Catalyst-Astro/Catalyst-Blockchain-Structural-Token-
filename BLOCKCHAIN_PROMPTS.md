# Prompts de entrenamiento para mantener y escalar la blockchain

Este documento incluye ejemplos de *prompts* que se pueden usar con Codex para tareas comunes de mantenimiento, escalabilidad y adaptación de la blockchain a nuevos requisitos.

## Mantenimiento
1. **Diagnóstico de nodos:**
   - `Describe el estado actual de los nodos de la red, señalando fallos o retrasos en la sincronización.`
2. **Actualización de software:**
   - `Explica los pasos para desplegar una nueva versión del software de nodo sin interrumpir la red.`
3. **Monitorización de métricas:**
   - `¿Qué métricas clave se deben vigilar para asegurar la salud de la cadena?`  
   - `Genera un script para recopilar y visualizar esas métricas.`

## Escalabilidad
4. **Incremento de capacidad:**
   - `Detalla estrategias para escalar la red y soportar mayor número de transacciones por segundo.`
5. **Optimización de almacenamiento:**
   - `Proporciona un plan para reducir el espacio ocupado por la cadena sin perder información relevante.`

## Adaptación a nuevos requisitos
6. **Integración de funcionalidades:**
   - `Describe cómo añadir un nuevo tipo de transacción al protocolo.`
7. **Cambio de algoritmo de consenso:**
   - `Resume los pasos para migrar de prueba de trabajo a prueba de participación.`
8. **Compatibilidad con regulaciones:**
   - `Genera una lista de controles para asegurar que la cadena cumple con requerimientos legales recientes.`

Estos prompts se pueden adaptar según el contexto específico de la red y servir como base para entrenar o instruir a Codex en tareas de operación y evolución de la blockchain.
