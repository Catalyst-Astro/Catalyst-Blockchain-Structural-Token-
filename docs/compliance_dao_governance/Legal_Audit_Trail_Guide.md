# Legal Audit Trail Guide (Draft)

Disclaimer: Operational draft. Not legal advice.

## Audit Trail Elements
- Proposal metadata (type, hashes, timestamps).
- Votes cast with wallet addresses and roles.
- Approval or rejection status.
- Execution events and action hashes.

## Reconstruction
An auditor can reconstruct: alert -> proposal -> vote -> execution using on-chain events and off-chain hashes.
