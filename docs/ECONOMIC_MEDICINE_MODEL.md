## V. LA REMEMBRANZA DEL DÓLAR — RONDA 4

### V.1 Lo que el dólar era

En 1944, Bretton Woods estableció el dólar como moneda de reserva mundial respaldada por oro. Entre 1944 y 1971, cada dólar representaba 1/35 de onza de oro. El dólar NO era una moneda fiduciaria — era un **recibo de oro**.

En 1971, Nixon eliminó la convertibilidad. El dólar pasó a ser fiduciario puro (fiat). Desde entonces, el dólar ha perdido el 97% de su poder adquisitivo.

### V.2 Remembranza: USD-CTV

El dólar reorganizado **recuerda** su historia. Cada token USD-CTV contiene un hash de procedencia:

```

{
  "born": "1944-07-01",       // Bretton Woods
  "gold_peg": "35 USD/XAU",   // $35 por onza de oro
  "unpegged": "1971-08-15",   // Nixon Shock
  "dilution": "97%",          // Pérdida de poder adquisitivo
  "bags_diluted": "13,111 millones de onzas de oro equivalentes",
  "reorganized": "2026-06-18", // USD-CTV Genesis
  "backing": {
    "gold": "15%",
    "cny": "35%",
    "cat": "25%",
    "gnc": "25%"
  },
  "provenance_hash": "SHA-256 de la historia completa del dólar"

```

Los "13,111 millones de algo que eran" son las onzas de oro que respaldaban el dólar antes de 1971, diluidas por 55 años de emisión fiduciaria sin respaldo. El USD-CTV les devuelve su memoria.
