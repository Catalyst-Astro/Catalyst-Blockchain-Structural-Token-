# Matriz de Roles y Facultades (Borrador)

> Documento preliminar. No constituye asesoria legal.

| Rol | Facultades principales | Restricciones / Controles |
| --- | --- | --- |
| Fideicomitente | Aporta activos, entrega documentos, propone cambios | No dispone del activo sin autorizacion del fideicomiso |
| Fiduciario | Titularidad legal del activo, administra cuentas y pagos | Actua solo conforme mandato e instrucciones aprobadas |
| Fideicomisario | Recibe rendimientos economicos | Sin derechos de propiedad directa |
| Comite Tecnico | Aprueba operaciones relevantes, reservas, contingencias | Reglas de quorums y actas registradas |
| DAO Council | Gobernanza on-chain, valida cambios de estatus | Limitado por reglas del fideicomiso |
| Trust Admin | Administra roles y altas en registros | Debe conservar evidencia documental |
| Legal Auditor | Actualiza hashes legales, revisa evidencia | No ejecuta pagos ni disposiciones |
| Oracle Operator | Reporta eventos operativos y cierres | No modifica documentos legales |
