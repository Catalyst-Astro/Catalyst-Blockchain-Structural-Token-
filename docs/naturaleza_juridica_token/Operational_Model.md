# Off-Chain Operational Model (Draft)

Disclaimer: Operational draft. Not legal advice.

## 1) Token Classification Process
- Define jurisdictional scope and legal narrative.
- Maintain a classification memo with periodic review.
- Update disclosure bundle hash when classification changes.

## 2) Disclosure Acceptance Process
- User completes identity verification off-chain.
- User accepts disclosures via clickwrap or e-signature.
- Acceptance is recorded on-chain by wallet signature.
- No personal data is stored on-chain; only hashes and timestamps.

## 3) Suitability and Caps
- Assign a risk profile per user (retail, accredited, institutional).
- Apply exposure caps and concentration limits.
- Update policy or lockups for wallets when needed.

## 4) Marketing and Communications
- Use approved claims only; avoid public solicitation language.
- Prohibit claims of guaranteed yield or liquidity.
- Maintain a library of approved statements and disclaimers.
