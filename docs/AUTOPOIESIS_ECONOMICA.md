## I. ¿QUÉ ES LA AUTOPOIESIS? (Origen y Definición)

### 1.1 Origen biológico — Maturana & Varela (1972)

Humberto Maturana y Francisco Varela acuñaron el término en 1972 para describir la cualidad fundamental de los sistemas vivos:

> **Autopoiesis** = Auto (sí mismo) + Poiesis (creación, producción)
> 
> Un sistema autopoiético es aquel que **se produce a sí mismo continuamente**. No es creado desde afuera — se regenera, se repara, se expande desde su propia dinámica interna.

Los 3 criterios de un sistema autopoiético:
1. **Clausura operacional** — El sistema define sus propias reglas de operación
2. **Autoproducción** — El sistema produce los componentes que lo constituyen
3. **Acoplamiento estructural** — El sistema interactúa con el entorno pero no es determinado por él

### 1.2 Autopoiesis ANTROPICA (Catalyst)

Catalyst introduce el **principio antrópico** a la autopoiesis:

> La economía no solo se auto-crea — se auto-crea **con propósito humano**. Cada trigger binario, cada proof chain, cada quema de CAT está vinculada a actividad económica real: un pago QR procesado, una transferencia SWIFT transmitida, una factura emitida.

**Autopoiesis sin principio antrópico** = sistema que crece sin propósito (ej: inflación descontrolada)
**Autopoiesis CON principio antrópico (Catalyst)** = sistema que crece vinculado a valor real

La **entropía** (2a ley de la termodinámica) establece que todo sistema cerrado tiende al desorden máximo. En economía:

```
Entropía económica =
```
