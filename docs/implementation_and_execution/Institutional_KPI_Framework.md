# Institutional KPI Framework (Draft)

Disclaimer: Operational KPIs. Not legal advice.

## Compliance KPIs
1) End to end traceability rate
- Target: >= 99 percent
2) AML alert resolution time (median)
- Target: <= 72 hours
3) Lockup compliance rate
- Target: >= 99 percent
4) Travel rule evidence coverage (when required)
- Target: >= 98 percent

## Risk and stability KPIs
5) Internal volatility vs external benchmark
- Target: <= 60 percent of benchmark
6) Price to asset decouple index
- Target: <= threshold set by DAO
7) Bubble absorption index (BAI)
- Target: >= threshold set by DAO

## Governance KPIs
8) Proposal cycle time (submission to execution)
- Target: <= 30 days
9) Audit findings severity
- Target: Critical = 0, High <= 2

## Operational KPIs
10) Onboarding time for verified investors
- Target: <= 10 business days
11) Incident containment time
- Target: <= 24 hours
12) Distribution reconciliation time
- Target: <= 7 days
