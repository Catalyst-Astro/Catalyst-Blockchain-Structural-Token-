# Pilot Project Playbook (Draft)

Disclaimer: Operational playbook. Not legal advice.

## Objective
Run the first project with a single series under full compliance gates, no secondary market.

## Steps
1) Configure compliance stack
- KYC/AML gate live
- Whitelist or SBT active
- Disclosures acceptance active

2) Deploy series
- Register series with metadata hash
- Set lockup schedule
- Set jurisdiction policy

3) Investor onboarding
- Eligibility checks
- Wallet approval
- Document acceptance

4) Primary allocation
- Controlled distribution
- Evidence hashes recorded

5) Distribution cycle
- Fiduciary revenue report
- Authorization to distribute
- Reconciliation logged

## Exit criteria
- Zero critical issues
- Full traceability on chain
- First distribution completed
