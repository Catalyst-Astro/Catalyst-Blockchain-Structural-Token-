# Adoption Phases Framework (Draft)

Disclaimer: Operational draft. Not legal advice.

## Goal
Define a phased path from private issuance to controlled secondary access.

## Phases
Phase 0 - Closed infrastructure
- No listing
- Whitelist only
- Internal pilots with fiduciary
- Freeze and audit paths tested
Exit criteria:
- KYC/AML live
- Disclosure acceptance live
- Whitelist or SBT enforced
- Emergency freeze tested

Phase 1 - Private primary market
- Private placement only
- Lockups active
- Eligible investors only
- No public marketing
Exit criteria:
- Offering registry active
- Investor eligibility verified
- Monitoring and alerts active
- Initial audit checkpoint recorded

Phase 2 - Controlled secondary market
- Whitelisted venues only
- Volume and frequency caps
- Travel rule enforced when applicable
- Listing policy active
Exit criteria:
- Venue due diligence complete
- Reporting stable and periodic
- Incident response dry run complete

Phase 3 - Expanded access (optional)
- Selected regulated venues
- DAO approval and fiduciary no objection
- Jurisdiction specific policies active

## Entry checks (ASCII)
KYC -> Eligibility -> Disclosures -> Whitelist/SBT -> Listing policy -> Transfer

## Governance flow (ASCII)
Proposal -> DAO vote -> Policy activation -> Evidence hash
