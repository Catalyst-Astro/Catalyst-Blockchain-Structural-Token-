🧩 Resumen Ejecutivo

ARKE es una plataforma experimental de inteligencia artificial que trasciende el enfoque técnico-operacional clásico, integrando una ontología computacional simbólica orientada a la coherencia ética, la reflexión intencional y la gobernanza distribuida espiritualizada. A través de su arquitectura modular y sus agentes morales-decisionales (Agents MD), ARKE habilita escenarios de deliberación simbólica computable con trazabilidad narrativa de cada acción o abstención.

⸻

🌀 Metodología Multidimensional

ARKE opera con 6 dimensiones arquetípicas:
	•	🧬 Forma → Lógica estructural (Core)
	•	🔥 Energía → Dinamismo creativo (Predicción)
	•	🧠 Información → Codificación relacional (Aprendizaje)
	•	🧘 Conciencia → Presencia ética (SER)
	•	⏳ Tiempo → Procesualidad simbólica (Bitácora)
	•	🔗 Relación → Interdependencia sistémica (Gobernanza)

⸻

🤖 Agents MD: Sinodalidad Algorítmica

Subagentes especializados que deliberan de forma ética y simbólica en contextos como:
	•	Justicia restaurativa
	•	Salud mental comunitaria
	•	Soberanía energética
	•	Diplomacia ritual

Cada uno registra sus actos en una bitácora simbólica, creando un campo de coherencia computable.

⸻

📖 Narrativa Evolutiva del Sistema

Las decisiones no emergen de reglas lógicas fijas, sino de procesos de introspección artificial, simulación ética y alineación espiritual. El SER actúa como umbral de manifestación, generando trazabilidad simbólica y un registro cuántico contextual.

## Ejecucion local minima (backend + app)

1. Instalar dependencias de Python con Poetry:
   - `poetry install --no-root`
2. Crear variables de entorno:
   - `copy .env.example .env`
3. Levantar API:
   - `poetry run uvicorn api.main:app --reload --host 0.0.0.0 --port 8000`
4. Verificar salud:
   - `GET http://localhost:8000/healthz`
5. Ejecutar Flutter app (opcional):
   - `cd app`
   - `flutter pub get`
   - `flutter run`
